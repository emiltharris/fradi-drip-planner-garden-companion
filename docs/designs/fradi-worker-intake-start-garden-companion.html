Implementation Notes

Why this is the strongest version of Garden Companion

The original concept risked becoming too friendly. This version fixes that by anchoring every bright, accessible piece of UI to an operational fact: offline safety, draft recovery, language selection, and workshop readiness.

One dominant action The start button owns the screen. That matches the real field task: begin the interview fast without scanning a dashboard.
Shared-view clarity Large icon blocks and plain labels make sense even when the gardener is only glancing over the worker’s shoulder.
Manufacturing stays visible The queue and the two-output story stop this from reading like a generic data collection form.

The six-step promise

1
Plot size and shape

Let the worker anchor the conversation with something visible and concrete.

2
Sun, slope, and soil

Use pictorial choices instead of typed description wherever possible.

3
Water source and distance

This is where the buildability story becomes real, so it deserves visible weight.

Outputs the user can trust

Gardener guide

A single-page visual PDF in the gardener’s language, built for print or phone handoff.

Workshop build sheet

Technical tubing, dripper, and machine settings calibrated to FRADI’s real extrusion and molding workflow.
